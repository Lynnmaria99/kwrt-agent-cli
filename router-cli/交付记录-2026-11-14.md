## 一、需求

> "这个软路由里可不可以安装个 CLI 来方便我用 AI 来管理？"

确认后确定三项范围：
1. 自研零依赖 CLI（不依赖 opkg 装包）
2. 顺手修复 opkg 软件源
3. 配置 SSH 密钥免密

## 二、交付物

### 1. 路由器上的 `kwrt` 命令

| 项 | 值 |
|---|---|
| 主文件 | `/etc/kwrt/kwrt`（34.9 KB，POSIX sh） |
| 调用入口 | `/usr/sbin/kwrt` → 软链接到主文件 |
| 放在 `/etc` 的原因 | `sysupgrade` 勾选"保留配置"时可随配置保留 |
| 外部依赖 | 无。只用固件自带 `busybox` / `ubus` / `uci` / `iwinfo` / `jsonfilter` / `nft` / `curl` |
| 输出 | 默认 JSON（AI/脚本友好）；`-t` 输出人类可读表格 |
| 版本 | 1.0.0 |

只读命令：`info` `status` `net` `route` `clients` `dhcp` `wifi` `services` `logs`
`firewall` `dns` `ping` `doctor` + `uci show/get` + `pkg update/search/installed/info` + `ubus` 直通

写命令（必须 `-y`）：`uci set/delete/commit/revert`、`svc start/stop/restart/enable/disable`、
`wifi reload`、`pkg install/remove`、`reboot`

### 2. opkg 源修复

原 `/etc/opkg/distfeeds.conf` 指向 `releases/24.10/`，上游实际只有 `releases/24.10.0/`，
导致 6 个源全部 404、`opkg update` 完全不可用。已改为官方 24.10.0 路径：

```
src/gz kwrt_core      .../releases/24.10.0/targets/mediatek/filogic/packages
src/gz kwrt_base      .../releases/24.10.0/packages/aarch64_cortex-a53/base
src/gz kwrt_luci      .../releases/24.10.0/packages/aarch64_cortex-a53/luci
src/gz kwrt_packages  .../releases/24.10.0/packages/aarch64_cortex-a53/packages
src/gz kwrt_routing   .../releases/24.10.0/packages/aarch64_cortex-a53/routing
# kwrt_kiddin9 已失效(404)，注释
```

- 原文件备份：`/etc/opkg/distfeeds.conf.bak.20261114`
- 修复后：`opkg update` 全部成功，可用包 **8990** 个

### 3. SSH 免密

路由上原本已有本机公钥（`id_ed25519_router`，108 字节那条），补了本机 `~/.ssh/config` 别名：

```
Host router kwrt
    HostName 10.235.1.1
    User root
    IdentityFile ~/.ssh/id_ed25519_router
```

用法：`ssh router kwrt info`。改 root 密码不影响密钥通道。

## 三、安全设计

- 只读命令无门槛；写操作未加 `-y` 一律拒绝，返回 `{"error":"need_confirmation",...}`，退出码 `3`
- `reboot` 前有 2 秒缓冲，可 Ctrl-C 中断
- 错误以 JSON 写 stderr，stdout 保持干净，方便 `| jq`
- 不开放任何网络端口，管理通道只有 SSH（原固件本就没装 LuCI/uhttpd）

## 五、修复过的自身缺陷（开发过程）

1. `jnum()` 不接受小数点 → `load` / `temperature_c` 输出 null，已修
2. `uci set key=value -y` 把 `-y` 当成值 → 重写参数解析，兼容 `key value` 与 `key=value`
3. 自检磁盘占用率用错字段（拿可用量算）→ 显示"已用 96%"，改为已用/总量
4. opkg 输出用 `IFS=' - '` 切分导致带连字符的包名被切碎 → 改用 `awk -F' - '`

## 六、注意事项

1. **不要从官方源装 kmod 内核模块**：Kwrt 为自编译内核 6.6.92，官方 kmod 版本不匹配，
   可能导致网络异常。纯用户态包（jq、tcpdump 等）安全。
2. 刷机后软链接可能丢失，补：`ln -sf /etc/kwrt/kwrt /usr/sbin/kwrt`
3. 升级 CLI：`scp router-cli/kwrt router:/etc/kwrt/kwrt`
4. 该固件精简掉了 `hostname` 等 applet，脚本内已改用 `/proc` 与 `ubus` 取值
5. 本设备无 Web UI（uhttpd 未装），rpcd/luci-rpc 的 ubus 对象仍在但无前端
